# Plano de implementação — SEC-COMP-AUDIT-01

## Fase 0 — Aprovação e escopo

1. Founder aprova owners, escopo e apetite de risco.
2. Segunda linha valida taxonomia e prioridades.
3. Primeira linha confirma sistemas e processos existentes.

## Fase 1 — Baseline P0

1. Completar os inventários.
2. Mapear obrigações e riscos.
3. Ajustar e aprovar políticas críticas.
4. Implementar controles RCM-SEC-001, RCM-EVD-001, RCM-AI-001, RCM-PRV-001 e RCM-AUD-001.

## Fase 2 — Evidência operacional

1. Executar controles por ao menos um ciclo.
2. Registrar evidências no catálogo.
3. Abrir exceções e CAPAs para lacunas.
4. Congelar data room v1.

## Fase 3 — Mock audit

1. Audit Readiness coordena walkthroughs.
2. Auditoria interna seleciona amostras e testa.
3. Founder recebe relatório de readiness limitado ao escopo.
4. Achados críticos bloqueiam declarações externas.
